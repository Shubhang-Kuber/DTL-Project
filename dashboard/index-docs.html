🚀 Quick Start

▶ Launch Dashboard
First time? Start here: Read QUICK_START.md or load sample data in the dashboard console.

To Load Sample Data:

1. Open dashboard → Open DevTools (F12) → Go to Console
2. Type: loadSampleData()
3. Press Enter → Form auto-fills → Click "Analyze Risk"

✨ Dashboard Features

📋

Screen 1: Assessment

Comprehensive student survey with 20+ questions, progress tracking, and optional feedback.

📊

Screen 2: Risk Summary

Color-coded risk classification with confidence score and clear explanation of assessment.

📈

Screen 3: Factor Analysis

Interactive bar chart showing 5 key factors affecting dropout risk with detailed explanations.

🎯

Screen 4: Recommendations

100+ rule-based recommendations personalized to student profile, priority-ranked and actionable.

🎨 Key Features

  • 4-Screen Flow - Complete assessment, results, analysis, recommendations
  • 5-Factor Model - Academic, Financial, Institutional, Motivation, Social
  • Explainable AI - Clear rules and logic, no black boxes
  • Mobile Responsive - Works on phones, tablets, and desktops
  • Accessible Design - WCAG 2.1 AA compliant, keyboard navigation
  • Client-Side Processing - No server needed, instant results
  • Rule-Based Recommendations - 100+ personalized suggestions
  • Sentiment Analysis - Analyzes student feedback text
  • Data Export - Export results as JSON for reporting
  • Well Documented - Code comments, guides, examples

🆘 Support & Help

Having issues? Check these resources in order:

  1. Check browser console (F12) for error messages
  2. Review QUICK_START.md troubleshooting section
  3. Read README.md for detailed documentation
  4. See CUSTOMIZATION.md for configuration help
  5. Review code comments in app.js and data.js
For Developers: All code is well-commented and modular. Check inline comments in app.js and data.js for implementation details. Use browser console for debugging (e.g., window.currentAnalysis).

🛠 Technology Stack

  • HTML5 - Semantic structure
  • CSS3 - Modern styling with variables and media queries
  • JavaScript ES6+ - Core logic and interactivity
  • Chart.js 4.4.0 - Data visualization
  • No dependencies - Only Chart.js from CDN, rest is vanilla JS
